# Dataset Dictionary

## Source
Olist Brazilian E-Commerce Public Dataset

## Source URL
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Purpose
Analyse historical revenue, customer repeat purchases,
customer cohorts, RFM segments, delivery performance,
and review scores.

## Data handling
- Preserve original CSVs locally.
- Do not commit dataset files to GitHub.
- Document cleaning and exclusion rules.
- Verify the source licence and attribution requirements.

## Limitations
- Historical data, not a current live feed.
- No direct campaign spend or marketing attribution.
- Customer retention calculations must use customer_unique_id.
